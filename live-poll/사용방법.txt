실시간 의견 모으기 (Live Poll) 사용 방법

■ 파일 구성 (live-poll 폴더)
  index.html    학생 참여 화면 — PIN 6자리 → 학번·이름 → 답하기
  teacher.html  교사 대시보드 — 활동 만들기, PIN 받기, 마감/삭제
  screen.html   결과 화면 (프로젝터용) — 막대그래프 · 원형 그래프 · 순위 · 워드클라우드 · 의견 카드 · 응답 목록
  config.js     Supabase 연결 정보 (비워 두면 데모 모드)
  schema.sql    Supabase 데이터베이스 설정 (한 번만 실행)
  common.js, style.css  공통 코드와 디자인

────────────────────────────────────────
1. 먼저 데모 모드로 시험해 보기 (설치 없음)
────────────────────────────────────────
  1) teacher.html 을 Chrome에서 엽니다. (config.js 가 비어 있으면 자동으로 데모 모드)
  2) '＋ 새 활동 만들기' → 질문, 응답 유형, 결과 표시 방식, 학생 정보 설정을 고르고 'PIN 받기'.
  3) 같은 브라우저에서 새 탭으로 index.html 을 열고 PIN을 넣어 학생처럼 답해 봅니다.
     (탭마다 다른 학생으로 취급됩니다.)
  4) 대시보드의 '결과 보기'를 누르면 결과 화면이 열리고, 답이 들어올 때마다 바로 바뀝니다.

  ※ 데모 모드는 이 컴퓨터의 브라우저 안에서만 작동합니다. 학생 크롬북과 연결하려면 2번을 하세요.
  ※ 파일을 더블클릭해서 열었을 때 탭끼리 연결이 안 되면, 아래 3번처럼 인터넷 주소로 열어 주세요.

────────────────────────────────────────
2. 여러 크롬북에서 실시간으로 쓰기 (Supabase 무료 플랜, 약 10분)
────────────────────────────────────────
  1) https://supabase.com 가입 → New project 만들기 (지역: Northeast Asia (Seoul) 추천).
  2) 왼쪽 메뉴 SQL Editor → New query → schema.sql 내용을 전부 붙여 넣고 Run.
  3) Project Settings → API 에서
       Project URL      → config.js 의 supabaseUrl
       anon public key  → config.js 의 supabaseAnonKey   에 붙여 넣고 저장합니다.
     (service_role 키는 절대 넣지 마세요. anon 키는 공개되어도 괜찮도록 설계되어 있습니다.)
  4) teacher.html 에서 이메일/비밀번호로 '처음이에요 (가입)' → 확인 메일의 링크 클릭 → 로그인.
     (확인 메일을 생략하려면 Supabase → Authentication → Sign In / Providers → Email 에서
      'Confirm email' 을 끄면 됩니다.)

────────────────────────────────────────
3. 학생들이 접속할 인터넷 주소 만들기 (GitHub Pages)
────────────────────────────────────────
  1) GitHub 저장소 → Settings → Pages → Branch 를 main / (root) 로 저장.
  2) 잠시 후 주소가 생깁니다. 예: https://<아이디>.github.io/English-Reading/live-poll/
       학생:  .../live-poll/            (PIN 입력)
       교사:  .../live-poll/teacher.html
  3) 대시보드의 '학생 링크 복사'를 누르면 PIN이 들어간 링크가 복사됩니다. (Google Classroom에 붙여 넣기)

────────────────────────────────────────
4. 활동 설정 안내
────────────────────────────────────────
  응답 유형: 객관식 · 복수 선택 · O/X · 별점 · 단어 입력 · 짧은 답변 · 의견 카드 · 순위 정하기
  결과 표시: 유형에 맞는 방식만 고를 수 있고, 결과 화면 위쪽 버튼으로 수업 중에 바꿀 수 있습니다.
             선생님이 바꾸면 학생 화면의 결과도 같은 방식으로 바뀝니다.
  학생 정보: 이름은 선생님만 보기(기본) / 친구들에게도 공개 / 완전 익명(학번·이름을 받지 않음)
             학번 받기·이름 받기를 각각 끌 수도 있습니다.
  결과 공개: 켜면 학생이 제출 후 친구들의 응답을 봅니다. 결과 화면에서 언제든 켜고 끌 수 있습니다.
  투표:      단어/짧은 답변/의견 카드에서, 결과 공개 시 친구 의견에 ♡ 투표 (한 번 더 누르면 취소).
  여러 번 응답: 끄면 학생이 다시 제출할 때 기존 답이 수정됩니다. 켜면 최대 20개까지 보낼 수 있습니다.

  결과 화면의 선생님 도구 (활동을 만든 선생님에게만 보임)
  · 화면에 학생 이름 표시: 프로젝터에 이름을 띄울지 선택 (기본은 꺼짐)
  · 응답 숨기기 버튼 보기: 부적절한 응답을 숨기면 그래프와 학생 화면에서 바로 빠집니다.
  · 응답 마감하기 / 다시 받기, 전체 화면

■ 개인정보
  · 학번·이름은 Supabase 데이터베이스에만 저장되고, 학생들은 선생님이 '공개'로 정한 이름만 볼 수 있습니다.
    (학생은 데이터베이스를 직접 읽을 수 없고, 정해진 기능으로만 접근합니다.)
  · 수업이 끝난 활동은 대시보드에서 '삭제'하면 응답까지 모두 지워집니다.
  · PIN은 누구나 입력할 수 있으므로, 활동이 끝나면 '응답 마감'을 눌러 주세요.
